## Installing
1. Open a download link on your phone and tap the file when it finishes.
2. Android asks to allow installs from your browser. Allow it.
3. If Play Protect warns, choose **Install anyway**. It appears for any app that did not come from the Play Store.

Each file is a stand-alone app.
